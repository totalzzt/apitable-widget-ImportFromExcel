# 导入 Excel 数据增强版 (Import Data From Excel - Advanced)

这是一个专为维格表 (APITable) 打造的增强版原生小程序应用。主要功能是帮助你轻松、定制化地将 `.xlsx` / `.xls` / `.csv` 文件中的大批量数据导入或更新到当前所在的维格表中。

## 功能特性

相对于内置基础版，本项目新增了更加高阶的控制能力、逻辑处理与预览视图：

- **多模式导入支持**：
  - **全量导入模式**：最基础的导入形式，将所有识别出的 Excel 数据行直接以新增记录形式追加至表格末尾。
  - **更新导入模式**：通过选取 **匹配主键** 检查新旧数据匹配状态。对表格中已存在的对应记录仅做 **更新填充**。
- **匹配主键定义**：允许使用者从下拉选项中选择一列作为新旧数据“寻找对比”的主键依据。
- **自定义增量添加条目（开关）**：在更新导入模式下，当有原本不存在的新条目被发现时，用户可自行决定是【直接新增入库】还是【忽略跳过该记录】。
- **多 Sheet 自由切换**：如果上传的 Excel 文件有数个工作表，通过下拉菜单实时更换解析 Sheet 的归属数据，系统即会自动重新映射新表头。
- **数据预处理预览**：为更平稳且安全的数据导入体验，系统提供了**预处理网格预览**功能。通过不同颜色与状态徽章（绿色新增、底色高亮蓝等）让用户先直观查阅所有执行方案，再进行实质导入操作。
- **更平滑可靠的切片执行过程**：优化大量数据执行底层通讯接口并发压力。以千条数据为批次，进行更加稳定的异步合并操作。

## 快速使用说明

### 1. 文件上传
点击首页 `选择Excel文件并上传` 按钮，导入需要更新的外部文件，文件解析成功后您将立即跳转至【配置参数】页。

### 2. 配置导入方案
在配置面板中：
- 可首先查看下方「Excel 数据预览」区域，确认解析出的文本和表头对不对得上。
- [多列配置] 有多个工作表时，通过 `选择工作表(Sheet)` 下拉框定位正确数据区。
- **配置导入模式**：
  - 若单纯想要导入所有数据：勾选 `全量导入 (直接新增)`。
  - 若旧表已存在部分存量数据想要进行覆盖：勾选 `更新导入 (匹配再更新)`。然后确保进一步选定作为两边对比的 **匹配主键栏**（如 "任务ID", "工号" 等）。最后决定当找不到对应的历史条目时，是否勾选 `是否允许增量添加条目` （不勾选则此类新增条目将被抛弃跳过）。

### 3. 查看数据预处理 (预览环节)
各项配置选择完毕后，请点击蓝色的 **数据预处理** 按钮。
此时进入执行方案的预览态，面板将展示本次操作将进行 **多少条新增、更新及跳过** 的统计数字，同时列表会按照具体的执行动作进行颜色划分。
你可以在此反复回退到配置页重置逻辑，直至状态全部吻合预估动作。

### 4. 执行操作并检阅结果
最终点击 **执行操作**，系统将展示 Loading，并且向空间底层执行批量修改。随后即通过大屏欢庆组件通知您的操作成果及记录汇总数量。

## 开发与调试 (Deployment / Dev)

如果您想要构建属于您自己的开发定制版扩展：

1. 克隆 / 下载本工程后，进入根目录并使用 npm 解决依赖：
   ```bash
   npm install --legacy-peer-deps
   # 或者 yarn install
   ```

2. 开启小程序的开发者控制台并本地环境映射运行：
   ```bash
   npm run start
   ```

3. 构建上传至系统：
   ```bash
   npm run release
   ```

更多底层开发规范请参阅 [维格表官方 Widget 开发者中心](https://github.com/apitable/widget-cli)。
